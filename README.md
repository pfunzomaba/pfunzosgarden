
# Pfunzo's Garden

## Description

Pfunzo's Garden is a responsive and modern gardening website designed to showcase fresh, organically grown produce. The website allows customers to browse products by category, view product availability and pricing, add items to a shopping cart, and enjoy a seamless shopping experience across desktop, tablet, and mobile devices.

Our mission is to cultivate healthy communities by providing fresh, high-quality produce grown with care.

---

## Features

- Fully responsive design for desktop, tablet, and mobile devices.
- Product catalogue with:
  - Product images
  - Prices
  - Stock availability
  - Quantity remaining
  - Quantity selectors (+/-)
  - Add to Cart functionality
- Shopping cart system with item counter.
- Product filtering by category:
  - All
  - Vegetables
  - Fruits
  - Herbs
  - Seedlings
- Load More button for improved user experience.
- Out-of-stock product handling.
- Interactive navigation menu.
- Footer with:
  - Contact information
  - Social media links
  - Navigation links
- Modern and clean user interface.
- Hover effects and interactive elements.

## Shopping Cart Features

- Add products to cart.
- Select product quantities before adding to the cart.
- Cart item counter displayed in the navigation bar.
- View selected items on the cart page.
- Continue shopping functionality.
- Cart information is stored using Local Storage.

---

## Product Features

Each product card includes:

- Product image
- Product name
- Product description
- Product price
- Stock availability
- Quantity remaining
- Quantity selector
- Add to Cart button
- Sold Out button for unavailable products

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/pfunzos-garden.git
```

2. Open the project folder.

3. Open the `index.html` file in your browser.

No additional installation or dependencies are required.
